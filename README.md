# Module-End--5-Module-End-Assignment-Python-For-Data-Analysis
https://drive.google.com/file/d/1jR0KqoLsO_OAh--82B_eSxBVYDxVlQnZ/view?usp=sharing
This project, **Social Media Engagement Analytics Using Python**, focuses on analysing social media data to understand user behaviour and engagement patterns. The assignment was completed using Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Plotly. It covers data importing, data cleaning, handling missing values, removing duplicates, data type conversion, data exploration, data wrangling, and statistical analysis. Python concepts such as filtering, grouping using `groupby()`, aggregation, descriptive statistics, and correlation analysis were applied. Various visualizations, including scatter plots, line charts, bar charts, pie charts, histograms, box plots, violin plots, pair plots, heatmaps, and interactive Plotly charts, were created to explore the data. Finally, the project identifies important insights and findings related to content performance, user trends, posting behaviour, and sentiment analysis.
